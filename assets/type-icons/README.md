# Pokémon type icon attribution

These 18 SVG symbols are copied from the [typeDex type icon assets](https://github.com/marcelolamenza/typeDex/tree/main/public/type-icons). The typeDex project documents them as local SVG copies of the official Pokémon type chart portal icons:

https://sg.portal-pokemon.com/game/type-chart/

The icons are bundled locally and rendered by `type-icon.js`; they require no runtime network requests. Pokémon and its marks are the property of their respective owners. These files are reused source assets, not original Type Battle artwork.
